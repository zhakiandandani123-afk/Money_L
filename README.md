# money L

Open `index.html` in a browser to use the app. No build step or account is needed.

The app opens with a clean slate: all totals start at Rp0, and transactions, goals, challenges, wishlist, and profile details start empty. Choose **Bahasa Indonesia** or **English** in Settings. Changes are saved in that browser with local storage and stay there after refresh. Use **Settings → Download my data** to export your data as JSON.
